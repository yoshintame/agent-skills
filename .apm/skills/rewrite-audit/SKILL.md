---
name: rewrite-audit
description: Независимая проверка /rewrite на потерю информации.
---

Вход — handoff от `/rewrite`: база (коммит до перекладки), диапазон, карта «старый файл → новые дома», список осознанных удалений. Предмет — сохранность знания, не раскладка: где что лежит, решено. Содержание прогнано `/actualize`: «устарело» ≠ «потеряно», факты не дочинивать — расхождение с реальностью в отчёт.

1. **Разложить диапазон.** `bun ~/.claude/skills/rewrite-audit/scripts/audit-map.ts <repo> <base> <head> [pathspec…]` — переезды с similarity, удаления, добавления. `R100` (тело не менялось) — только frontmatter; остальные переезды и удалённые — по карте; добавленные — дома. Оригинал: `git -C <repo> show <base>:<path>`.
2. **Units, не абзацы.** По каждому старому файлу: факт, число, команда, оговорка, отвергнутая альтернатива с причиной, открытый пункт, ссылка — и найти каждый в домах. Переписанные начисто файлы — по субагенту на файл, только чтение: вход — старый текст и дома, выход — ненайденные units. Правки — в основной сессии.
3. **Что не потеря** — те же гарды, что у перекладки, иначе срезанное вернётся:
   - разворотный язык и хроника в current-state доке (Гард 1);
   - пересказ кода в implementation-spec — списки файлов, инвентарь команд, раскладка директорий (Гард 5);
   - резолвленные open-questions и defer-крошки без своего вопроса;
   - вводные-клей и дубли hub ↔ спека;
   - список осознанных удалений handoff'а.
   Спорное — в отчёт, не в файл.
4. **Куда возвращать.** По роли, не в hub: rationale и user input — decision или frozen analysis, не спека; открытый пункт — open-question; рецепт — knowledge. Оговорки оригинала («если есть», «не проверено») проверить или сохранить — не превращать в факт.
5. **Ссылки по смыслу.** Перекладка нацеливает бэклинки удалённых файлов механически (всё → hub); каждый — на точную цель: пункт backlog'а → его open-question или decision, community-evidence → deep-research, `[[area]]` вместо проекта или его фаз → проект.
6. **Чужой WIP.** Файл, грязный до аудита, коммитить своим ханком: `git-commit-atomic -C <repo> --auto "<msg>" <файлы> -- <patch>` — позиционный файл стейджится целиком.
7. **Отчёт** по каждому файлу карты: `полностью` / `потеряно: <units> → <куда>` / `осознанно снято`; спорные units — отдельным списком.
8. **Обратный handoff.** Аудит смещён к «вернуть», перекладчик — к «срезать», и только он знает, почему срезал. Закончить `/handoff-create` для сессии с `/rewrite`: диапазон коммитов аудита, отчёт, отдельно «восстановлено в current-state док» и «спорное, не трогал». Ревью — шаг 7 `/rewrite`.
