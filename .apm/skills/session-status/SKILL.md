# /session-status

Каждое утверждение о текущем состоянии — из команды этого захода (`git diff`, чтение файла), не из памяти транскрипта. Не пиши «не изменилось» без diff'а.

## Шаги

1. Прогнать скрипт:
   ```
   bun ~/.claude/skills/session-status/scripts/session-status.ts [session-id]
   ```
   Без аргумента — берёт `CLAUDE_CODE_SESSION_ID` из env (текущая сессия); если env нет — latest по mtime в cwd. Полный UUID — конкретная. Шапка несёт `Reconstructed as-of` + `HEAD at snapshot` — перенеси в итог. `moved → <новый путь>` — уцелевший переезд, не потеря. Если пишешь отчёт позже отметки — перегони скрипт.

2. Перечитать файлы с пометкой `re-read needed`: `git -C <repo> diff <hash> HEAD -- <file>` → точная дельта (какие поля, секции, строки изменились и что там теперь — не «файл изменён») + жив ли контент сессии. `BYTE-IDENTICAL` не трогай.

3. Проверить актуальность: для ключевых артефактов и решений сессии — `git log`, `git diff`, чтение файла. Убедиться, что мир не разъехался с момента сессии.

4. Вывод — нарратив, не инвентарь. Скрипт даёт сырые данные (файлы, коммиты, staleness) — это вход, а не формат ответа.

## Вывод

```
## Session <short-id>
_снято: <as-of> · HEAD <репо>@<hash>_

### Что сделали
<Нарратив: что было сделано и зачем. 2-5 строк прозой. Коммиты и пути — подкрепление внутри текста, не отдельный перечень.>

### Ключевые решения и инсайты
1. <Конкретный факт, решение или разворот — то, что без этой сессии не узнать.>

### Где остановились
<На каком шаге пауза, что ждёт действия, какой вариант выбран но не реализован.>

### Актуальность
<Что проверено командами и совпало / разошлось с ожидаемым. Не `BYTE-IDENTICAL`, а содержательно: «конфиг не менялся, wildcard на месте».>

### Полезное, ещё не зафиксировано
- <Остаточное: команда, цифра, баг, doc-ошибка — конкретика, которая исчезнет с контекстом.>
```

| Раздел | Правило |
|---|---|
| Что сделали | Проза, не буллеты. Данные скрипта вплетай в текст, не копируй секциями |
| Решения и инсайты | Нумерованный список. Каждый пункт — конкретный факт или развилка с выводом |
| Где остановились | Точка остановки + что ждёт. ≤3 строки |
| Актуальность | Только проверенное командами. Неизменённые файлы — одна сводная фраза |
| Полезное | Residual: факты, которые не вошли выше и исчезнут. Не дублируй решения/инсайты |

- Пустую секцию пропусти.
- `Documentation`, `Code (commits)`, `Non-git / scratch` из скрипта — не отдельные секции в выводе; данные для нарратива.
- Чужая сессия (UUID, нет контекста): инферируй из subject'ов коммитов и путей; невозможно — флагни и предложи `claude --resume <UUID>`.

**Резюм и sandbox.** Headless запуск (`claude -p --resume <UUID> "/session-status"`) — дозапись в `~/.claude/projects/**` в write-deny: гони с `dangerouslyDisableSandbox: true`. Чужой slug — `(cd <slug-как-путь> && claude --resume …)` либо `session-link`.
