# KeySwitcher threat model

Baseline established by a full static audit of v0.2.6 (commit 7166f68), carried forward by diff audits to **v0.3.0 (commit 0a51fc2)**. A diff is clean only if it weakens no baseline below; any change in the right column blocks until explained. Cite `file:line` at the new tag for every judgement.

| Area | Audited baseline | Block until explained |
|---|---|---|
| Network | Egress only in `LLMPolisher.swift`, over its own ephemeral `URLSession` from `LLMTransport.swift` (no cache, recreated after two network errors). Targets: worker `https://qkb-llm.graninilya.workers.dev` (POST `{model, text}`, no auth), then each user-set `aiMirrorURLs` entry (empty by default), or a user-set OpenAI-compatible endpoint. Fires **only** from the `polishText` hotkey (`AppDelegate.polishText`). No other `URLSession` or socket. | A new `URLSession`, `URLRequest`, `URL(string:`, `NWConnection`; a new host; a send not gated behind an explicit user action; anything that makes `aiEnabled` send more. |
| Update integrity | Sparkle. `SUFeedURL = https://github.com/graninilya/keyswitcher/releases/latest/download/appcast.xml`, `SUPublicEDKey = +VYV2MzhMzAQl+Qwb7wPPR4HldDmiINfqpiU8kva9Mo=`, updates EdDSA-verified against that key. | A changed `SUPublicEDKey` (rotation is high-risk; confirm the author did it on purpose), a `SUFeedURL` host change, anything that disables EdDSA verification. |
| Capture | `CGEvent.tapCreate(..., options: .listenOnly, ...)`, mask `keyDown \| flagsChanged`. Password fields excluded via `SecureInput.isEnabled`: `IsSecureEventInputEnabled()` cached 150 ms, rechecked on Tab/Return, app activation and mouse clicks; buffer cleared on each secure-input transition (`KeystrokeBuffer.handle`); `SelectionDetector` AX reads skipped under secure input. | Tap `options` other than `.listenOnly`; new event types in the mask (`keyUp`, mouse content); a dropped or weakened secure-input guard (removed check, longer TTL, fewer rechecks). |
| Synthetic input | Only `InputInjection.emit` posts, at `.cghidEventTap`, from a fresh `.privateState` source, every event tagged `eventSourceUserData = 0x514B4201` so the tap drops it (fallback: ignore typing 200 ms after an injection). It types only backspace (key 51), whole strings on key 0 via `keyboardSetUnicodeString`, and four ⌘ chords: ⌘C, ⌘L, ⌘→, ⌘⇧←. Never ⌘V, ⌘A, Return. Triggers: a word completed by real typing (autoconvert, retro chain) and the user's hotkeys; polish types the LLM reply verbatim. Known gap: injection itself has no secure-input check. | A new key, chord or event type posted (⌘V, ⌘A, Return, mouse); injection driven by a timer, the network, IPC or a file; a changed or removed tag check; a new injection path; polish typing a reply with fewer checks or into another app. |
| Clipboard and AX selection | Never pastes; replacement is always typed. Reads `NSPasteboard.general` only after its own ⌘C, when AX gives no selection (smartConvert, polish fallbacks), after `backupPasteboard`; `restorePasteboard` runs on every exit path but ignores the snapshot's `changeCount`, so a copy made while polish waits is lost. Overwrites the clipboard without restore only from the diagnostics buttons and `--test-injection`. AX: reads selected text and range, writes only `kAXSelectedTextRangeAttribute` (polish selects the paragraph), all skipped under secure input. Single words from hotkey swaps and reverts persist in `UserDefaults` (`forceSwapWords`, `ignoredAutoSwap`, exported). | A `setString`/`writeObjects` outside restore and the diagnostics buttons; synthesized ⌘V; a skipped or delayed restore; pasteboard or selection text logged without `Log.redact`, stored anywhere new, or sent without a hotkey; `AXUIElementSetAttributeValue` on any other attribute. |
| Hotkeys and input source | Defaults: left ⌥ tap smartConvert (undo within 5 s), right ⌥ tap polish, Carbon `RegisterEventHotKey` ⌥⇧F forceSwap, ⌥⇧T transliterate, ⌥⇧P typography; toggleEnabled unbound. Every action hotkey is muted while disabled, paused or in mode `.off`, except toggleEnabled. `TISSelectInputSource` only after an injection, among the user's enabled `ru`/`en` sources. Four `addGlobalMonitorForEvents`, all mouse-down only, handlers ignore the event. | A new default hotkey or global monitor; a monitor on key events or reading the event; a hotkey acting while disabled, paused or `.off`; switching input source without a user-driven replacement, or over all installed sources. |
| Storage and persistence | `UserDefaults` for settings, lowercased word sets, per-app rules and counters. Custom API key in Keychain (`KeychainStore`, service `com.granin.keyswitcher`), never exported. `History` is RAM-only. Settings export/import only through a user-picked file. Login item via `SMAppService.mainApp`, user-toggled. | Any file or DB write of keystrokes; writes outside `UserDefaults` and the app container; plaintext secrets; a new `LaunchDaemon`/`LaunchAgent`. |
| Dependencies | One SPM dependency, `sparkle-project/Sparkle` (`from: "2.6.0"`); no `Package.resolved`. | A new `.package(` or `binaryTarget`, a changed Sparkle source or version source. |
| Dynamic code | None in app sources: no `dlopen`, `dlsym`, `NSClassFromString`-for-exec, `Process`, `NSTask`, `system`, `popen`, `NSAppleScript` (the only `osascript` is in the DMG-layout build script). `--self-test` and `--test-injection` run local checks only. | Any of those added to app sources. |
| Logging | User text goes through `Log.redact` (length and script mix only); plaintext only with the `QKBVerboseLogging` default. | A `privacy: .public` interpolation of raw user text. |
| CI (`.github/`) | — | New secrets, new `curl` or network calls in `release.yml` or its scripts, a changed signing identity, steps that fetch and run extra code. |
| Entitlements, `Info.plist` | — | A new entitlement, a sandbox change, a new usage-description string (camera, mic, contacts, full disk), a changed bundle id. |

Known baked-in URLs, matching the allowlist in `~/.config/desvio/keyswitcher/gates/verify.sh`: appcast and UI links under `github.com/graninilya/keyswitcher`, the worker URL, the `api.openai.com` placeholder text in `SettingsWindow.swift`, and `https://ya.ru/a,b` (typography self-test data in `SelfTest.swift`, never fetched).

Accepted deviations in our own branches, reviewed once: `local-fixes` makes the smartConvert hotkey switch the input source while disabled or paused (`whenMuted: InputSourceSwitcher.toggle()`, no text read or typed). Anything beyond that is judged against the table.

`desvio run diff` lists only added and removed lines matching these patterns, as `path:line` at the new tag (`+`) or the old one (`-`), and marks binary files without scanning them. Renames and logic changes inside existing functions do not show there — read the full diff.
