---
name: done
description: Закрыть сессию — зафиксировать вывод и пометить done.
---

Закрытие сессии = фиксация; переименование — побочный эффект. Каждый шаг — существующий примитив, зови его через Skill tool, не воспроизводи его логику сам.

1. **`/extract`** — полный прогон: классификация вывода сессии, роутинг по артефактам, аудит связанного, гарды, коммит (вшит в `/extract` финальным шагом).
2. **Проверь остаток.** Пробеги сессию: жил ли в чате контекст, который не лёг в артефакт на шаге 1 — договорённость, развилка, рабочая команда, цифра? Если да — вернись в `/extract`-прогон и дозафиксируй. Закрытая сессия не должна уносить с собой ничего важного: в отличие от `/paused`, fallback'а на `/session-status` здесь нет.
3. **Гейт незакоммиченного.** `bun ~/.agents/skills/session-status/scripts/session-status.ts --uncommitted` сверяет тронутое сессией и её сабагентами (Edit/Write, побочные эффекты Bash-вызовов, stash) с `git status` каждого репо, где сессия работала. Каждый пункт `Blocking` распорядись:
   - `commit` — `/git-commit`, позиционно только эти файлы;
   - `discard` — откатить свою правку;
   - `leave` — только намеренно локальное (тумблер для локального запуска, scratch) или файл, где поверх твоей лежит чужая правка.

   «Чужой репо» и «коммит за пользователем» — не причина для `leave`: тронул — коммить. `Not attributed` по транскрипту не твоё — не трогай. Перезапускай, пока `Blocking` не опустеет.
4. **`/rename-session done`** — пометить 🟢. Скрипт сам повторяет гейт и откажет, пока `Blocking` не пуст; каждый пункт из `leave` передай `--leave <abs-path>=<причина>` и назови пользователю в итоге.
5. **Убить процесс сессии.** Безусловно вызови `bun ~/.agents/skills/reset-sessions/scripts/reset-sessions.ts --self`. Если нечего убивать (SDK, нет процесса) — скрипт выйдет штатно; ничего не пиши пользователю по этому поводу. Если скрипт запустил worker — заверши ход коротким итогом: worker дождётся конца хода, перепроверит, что титул всё ещё 🟢, и погасит процесс; новый промпт пользователя флипает титул в 🔴 и отменяет kill.

Сессия-разговор без вывода: шаги 1–2 схлопываются в «нечего фиксировать», сразу шаги 3–5.
