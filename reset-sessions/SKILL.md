---
name: reset-sessions
description: Ресет Claude Code сессий VSCode-расширения кроме текущей
---
Запусти скрипт и передай пользователю его сводку дословно:

```
bun ~/.claude/skills/reset-sessions/scripts/reset-sessions.ts
```

Скрипт убивает все `claude` native-binary процессы VSCode-расширения, кроме поддерева текущей сессии (щадит процесс, из которого сам запущен). Печатает: сколько сессий убито, сколько МБ освобождено, сколько осталось.

Флаги: `--dry-run` — показать цели, ничего не трогая; `--all` — не щадить текущую (для запуска вне сессии).

Убитые сессии не потеряны: транскрипты в `~/.claude/projects/`, возобновляются через `Cmd+Shift+T` или Session history. Вкладки респавнятся лениво — только при клике.
