---
name: reset-sessions
description: Ресет Claude Code сессий VSCode-расширения кроме текущей
---
Запусти скрипт и передай пользователю его сводку дословно:

```
bun ~/.claude/skills/reset-sessions/scripts/reset-sessions.ts
```

Скрипт убивает все `claude` native-binary процессы VSCode-расширения, кроме поддерева текущей сессии (щадит процесс, из которого сам запущен), и добивает осиротевшие дочерние процессы (MCP-сайдкары, шеллы). Печатает: сколько сессий убито, сколько МБ освобождено, сколько осталось.

Флаги: `--dry-run` — показать цели, ничего не трогая; `--all` — не щадить текущую (для запуска вне сессии); `--self` — убить собственную сессию после конца хода (последний шаг `/done`, не для ручного вызова: отцепляет worker, который ждёт `end_turn` в JSONL, перепроверяет титул 🟢 и шлёт SIGTERM с эскалацией; кап 5 минут; лог `~/.local/state/cc-reaper/self.log`).

Убитые сессии не потеряны: транскрипты в `~/.claude/projects/`, возобновляются через `Cmd+Shift+T` или Session history. Вкладки респавнятся лениво — только при клике или следующем сообщении.

Рядом лежит `session-reaper.ts` — idle-reaper на launchd (модуль `session-reaper`), который гасит сессии, простаивающие дольше порога; вручную: `bun ~/.claude/skills/reset-sessions/scripts/session-reaper.ts --dry-run`. Лог убийств всех поверхностей — `~/.local/state/cc-reaper/kills.jsonl`.
